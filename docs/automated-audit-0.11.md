# Milestone 0.11 automated audit

The final automated gate covers the host-independent clipboard matrix, stable-address paste planning, rollback behavior, existing edit and Apply regressions, Windows Native AOT runtime execution, win-x64 Native AOT plugin publishing, and installable package creation.

Real Notepad++ 8.9.7 x64 clipboard focus, Excel/LibreOffice interoperability, and visual interaction remain owner host-acceptance gates. This document does not claim those host observations before they are performed.
