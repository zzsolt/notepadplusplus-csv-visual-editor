# Changelog

## 0.13

- Add combined column conditions and three-level text/numeric sorting.
- Add current-view column summaries with value frequencies and numeric ranges.
- Add filter previews, reset controls and menu/toolbar access.

## 0.12

- Add navigation from table cells to source fields.
- Add previewed replacement, trimming and case transformations.
- Add icon toolbars, complete text menus and an About dialog.
- Improve search navigation, space markers, layout and high-DPI rendering.
- Harden clipboard bounds and document-change handling.

## 0.11

- Add rectangular copy, cut and paste, including spreadsheet interoperability.
- Improve row selection, edit controls and large-table rendering.

## 0.10

- Add strict encoding checks and Windows-1250 Apply support.

## 0.9

- Add stable multi-row selection and atomic row deletion.
- Improve row indicators and selection rendering.

## 0.8

- Add row insertion and deletion with reversible pending changes.

## 0.7

- Add cell editing, conflict-checked Apply and Revert All.

## 0.6

- Add table search and view sorting.

## 0.5

- Add a read-only CSV grid and parser diagnostics.

## 0.1-0.4

- Establish the native plugin, docked panel, CSV parser and dialect detection.
